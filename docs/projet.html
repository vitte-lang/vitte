Comprendre l’état du compilateur

L’état de Vitte ne se résume pas à une étiquette unique. Une construction peut figurer dans la grammaire sans être prise en charge uniformément par le parseur, l’analyse sémantique, le backend ou l’exécution. Pour distinguer ces niveaux, consultez la matrice de support et lisez les preuves avec la version du dépôt à laquelle elles se rapportent.

La documentation est organisée pour séparer les usages :

  • Apprendre pour suivre les notions dans un ordre progressif.
  • Référence pour retrouver une construction, un terme ou un état de support.
  • Guides pratiques pour construire le compilateur, organiser un projet et diagnostiquer un échec.
