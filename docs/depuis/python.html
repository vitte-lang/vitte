Un ordre de lecture utile

  1. Commence par un programme complet et ses commandes.
  2. Continue avec valeurs et types, puis expressions.
  3. Apprends conditions et boucles, puis l’organisation des modules.
  4. Pour manipuler des données structurées, suis le guide du module JSON et lance les exemples confirmés indiqués sur la page.
Conserve la démarche expérimentale de Python.

Modifie un exemple, prédis le résultat, lance la commande puis compare. La différence pratique est que les étapes de lexing, d’analyse, de compilation et d’exécution Vitte peuvent échouer séparément ; la page CLI et diagnostics les explique.
