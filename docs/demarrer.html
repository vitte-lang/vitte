Installer, écrire, vérifier, comprendre les erreurs

Un seul parcours pour découvrir Vitte : terminez les étapes dans l’ordre, puis choisissez une référence ou un tutoriel de projet.

Prérequis : un terminal et un éditeur de texte. Pour exécuter le programme, il faut aussi un compilateur C hôte pris en charge.

1. Installer

Suivez les instructions d’installation à jour, puis vérifiez que la commande est disponible :

vitte --version

2. Écrire un programme complet

Créez le fichier hello.vit avec ce programme complet :

space examples/hello;

proc main() -> int {
    print("Hello from Vitte!");
    return 0;
}

Le point d’entrée affiche une ligne puis renvoie le code de sortie du processus. Le même exemple est disponible dans examples/hello.vit du dépôt.

3. Vérifier le programme

La commande check valide le fichier sans produire ni exécuter un programme :

vitte check hello.vit

Si aucune erreur n’est signalée, continuez. Sinon, gardez sous les yeux le fichier et la ligne indiqués.

4. Comprendre et corriger une erreur

Remplacez temporairement l’expression de retour par un nom inconnu :

space examples/hello;

proc main() -> int {
    let user_count = 2;
    return user_coutn;
}

Enregistrez cet exemple sous typo.vit, vérifiez-le, puis demandez au compilateur la signification du code public :

vitte check typo.vit
vitte explain E0401

Corrigez le nom puis vérifiez de nouveau le même fichier :

space examples/hello;

proc main() -> int {
    let user_count = 2;
    return user_count;
}
vitte check typo.vit

E0401 signale un nom inconnu. Son explication indique la cause et peut suggérer user_count.

5. Exécuter le programme

Quand le fichier passe la vérification, compilez-le et lancez-le sur la machine hôte :

vitte run hello.vit

Cette commande nécessite une chaîne de compilation C hôte prise en charge. Pour les phases de diagnostic, la sortie JSON et le dépannage, consultez le guide des diagnostics · EN.

Étapes suivantes

  • Retrouver la syntaxe et les types dans la référence du langage · EN.
  • Choisir un tutoriel de projet facultatif, selon votre objectif.
  • Parcourir les modules dans le catalogue de la bibliothèque · EN.
