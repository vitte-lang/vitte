Installer Vitte

Cette page sert à obtenir le compilateur et vérifier son installation. Pour écrire votre premier programme, poursuivez avec le parcours débutant.

Choisir une installation

  • Paquet publié : consultez la page des versions Vitte et choisissez l’artefact correspondant à votre système.
  • Depuis le dépôt : suivez les instructions de compilation maintenues dans le dépôt, notamment le guide de compilation · EN et les cibles Make · EN.

Vérifier l’installation

Dans un nouveau terminal, vérifiez que l’exécutable est accessible et affiche sa version :

vitte --version

Si la commande n’est pas trouvée, vérifiez le dossier d’installation dans votre variable PATH, puis ouvrez un nouveau terminal.

À savoir avant d’exécuter un programme

vitte check FILE vérifie le fichier sans génération de code. vitte run FILE compile et lance le programme pour le sous-ensemble pris en charge; cette étape requiert aussi un compilateur C hôte compatible.

vitte check hello.vit
vitte run hello.vit

Pour savoir quelles parties du langage et du compilateur fonctionnent de bout en bout, consultez la matrice de couverture · EN.
