Install, write, check, understand errors

This is the single beginner path through Vitte: complete the steps in order, then choose a language reference or a project tutorial.

Prerequisites: a terminal and a text editor. Running a program also requires a supported host C compiler.

1. Install

Use the current installation instructions, then confirm that the command is available:

vitte --version

2. Write one complete program

Create hello.vit with this complete program:

space examples/hello;

proc main() -> int {
    print("Hello from Vitte!");
    return 0;
}

The entry procedure prints one line and returns a process status. The same example is available as examples/hello.vit in the repository.

3. Check it

Run the semantic checks without generating or executing a program:

vitte check hello.vit

If the command reports no errors, continue. If it reports an error, keep the file and line number in view.

4. Understand and fix an error

Temporarily change the return expression to an unknown name:

space examples/hello;

proc main() -> int {
    let user_count = 2;
    return user_coutn;
}

Save that example as typo.vit, check it, then ask the compiler what the reported public code means:

vitte check typo.vit
vitte explain E0401

Correct the final name and check the same file again:

space examples/hello;

proc main() -> int {
    let user_count = 2;
    return user_count;
}
vitte check typo.vit

E0401 reports an unknown name. Its explanation gives the cause and may suggest user_count.

5. Run the program

Once the file checks, compile and execute it on the host:

vitte run hello.vit

This command needs a supported host C toolchain. For more diagnostic phases, JSON output and troubleshooting, see the diagnostics guide.

  • Choose an optional, domain-specific project tutorial.
