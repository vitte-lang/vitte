Construire depuis le dépôt

make
vitte --version
vitte check examples/hello.vit

Le dépôt utilise un frontend natif pour un sous-ensemble et un chemin bootstrap/compatibilité pour certaines sources. Le README racine et src/docs/language_coverage.md ne reflètent pas tous le même état que les tests et le README du driver ; la matrice État du support indique les preuves à privilégier.

Options utiles du CLI documenté

  • L’installation de paquets avec vitte install est à venir. Pour installer JSON actuellement, suivez les étapes manuelles de la fiche du module JSON.
  • --diagnostic=terminal|json|sarif|lsp choisit le format du diagnostic.
  • --stop-after-lexer, --stop-after-parser, --stop-after-sema arrêtent le pipeline à une étape.
  • --emit-tokens, --emit-ast, --emit-hir, --emit-ir, --emit-c demandent des sorties intermédiaires lorsque l’étape est disponible.
  • --target, --backend, --profile et -o configurent cible, backend, profil et fichier de sortie.
  • --manifest-path, --project-root et VITTE_MODULE_PATH aident à résoudre la configuration et les modules.

La présence d’une option dans l’aide ne garantit pas que chaque construction soit acceptée ou puisse produire un exécutable. Les tests runtime vérifient des programmes précis ; consulte les matrices par construction avant de dépendre d’une fonctionnalité.

Lire un diagnostic

  1. Lis le code et le titre : ils identifient la classe du problème.
  2. Vérifie la phase et l’emplacement dans la source.
  3. Lis les notes et suggestions qui accompagnent le message.
  4. Corrige d’abord l’erreur la plus proche de sa cause ; les erreurs suivantes peuvent en découler.

Codes fréquents et reproductions

Les codes ci-dessous sont enregistrés dans le registre stable du compilateur et reproduits par les fixtures du dépôt avec Vitte 0.1.1. Le code public est destiné à être recherché ; le symbole interne permet de relier le cas au registre et aux tests.

Code publicSymbole internePhase et sens
E0102VITTE_LEXER_E_UNTERMINATED_STRINGLexer : littéral de chaîne non terminé.
E0201VITTE_PARSER_E_EXPECTED_TOKENParser : token requis manquant, comme un point-virgule.
E0301VITTE_IMPORT_E_MODULE_NOT_FOUNDImports : chemin de module impossible à résoudre.
E0401VITTE_RESOLVE_E_UNKNOWN_SYMBOLRésolution : nom absent de la portée ou des imports.
E0512VITTE_TYPE_E_INVALID_OPERANDTypes : opérande incompatible avec l’opérateur.
E0601VITTE_CALL_E_ARITYAppel : nombre d’arguments différent de la signature.
E0902VITTE_BACKEND_E_CODEGENBackend C17 : génération impossible pour une construction atteinte.

Les corrections, les commandes exactes et les sources négatives vérifiées figurent dans le guide des erreurs courantes. Pour un code différent, utilisez vitte explain CODE ; ne déduisez pas qu’un code d’une phase donnée implique automatiquement un défaut dans votre logique métier.
