Contexte du registre

La liste ci-dessous est celle de src/bootstrap/builtin/README.md. Elle décrit le registre bootstrap, pas nécessairement chaque type que la grammaire, les fixtures ou un autre backend peuvent accepter.

Types intégrés listés

FamilleTypes
Contrôle et diagnosticvoid, never, error, bool
Entiersu8, u32, u64, usize, int, i64
Flottantsf32, f64
Textestring

Les modules et tests du dépôt utilisent également des types tels que i8, i16, i32, u16, char et d’autres. Ce décalage doit être vérifié contre la table builtin réellement compilée avant d’afficher une liste exhaustive.

Opérateurs du registre

  • Numériques : + - * / %.
  • Entiers et bits : & | ^ << >>.
  • Comparaison : == != < <= > >=.
  • Logique : and or.
  • Unaires : ! + - ~.

Le registre indique que les opérations numériques et binaires attendent actuellement des types d’opérandes correspondants. La table ne remplace ni les règles complètes de typage ni la priorité définie par la grammaire.
