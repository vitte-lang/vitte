Alias de type
Nom supplémentaire qui désigne un type existant, déclaré avec type.
AST
Arbre syntaxique abstrait : représentation structurée obtenue après l’analyse grammaticale du source.
Backend
Étape qui transforme une représentation intermédiaire vers une cible, comme du code machine ou C17.
Builtin
Symbole intégré au compilateur, au runtime ou à la plateforme, plutôt que défini par une bibliothèque Vitte ordinaire.
Contrat
Précondition ou postcondition d’une procédure, exprimée avec requires ou ensures.
Déclaration
Construction qui introduit un nom ou une entité : procédure, type, constante, module ou autre élément de niveau supérieur.
Expression
Construction qui calcule ou désigne une valeur ; elle peut être utilisée dans une instruction ou comme argument.
Forme (form)
Type composé constitué de champs nommés.
Générique
Déclaration paramétrée par un ou plusieurs types, pour réutiliser une logique à plusieurs types concrets.
Grammaire
Règles formelles qui précisent quelles suites de tokens forment une construction valide.
HIR
Représentation intermédiaire de haut niveau entre l’AST et les étapes de compilation suivantes.
Implémentation (impl)
Bloc qui relie des déclarations à un type et éventuellement à un trait.
Import
Déclaration use qui rend un module ou un symbole accessible depuis le fichier courant.
Invariant
Propriété qui doit rester vraie pendant une opération ou à la frontière d’un bloc de code.
Lexer
Composant qui découpe le texte source en tokens.
Module
Unité nommée par space qui rassemble des déclarations et définit des frontières de visibilité.
Nullable
Type qui peut représenter une valeur présente ou l’absence, souvent notée ?T dans les sources de core.
Parser
Composant qui vérifie l’organisation des tokens selon la grammaire et construit l’AST.
Portée
Zone de code dans laquelle un nom est visible et peut être utilisé.
Référence
Accès à une valeur existante, noté par exemple &T ou &mut T.
Sémantique
Règles qui donnent leur sens aux constructions : résolution des noms, types, mutabilité et contraintes.
Token
Unité lexicale produite par le lexer : identifiant, mot-clé, opérateur, littéral ou ponctuation.
Trait
Contrat de comportement partagé par des types, déclaré avec trait.
Type opaque
Type dont les utilisateurs ne voient pas directement la représentation interne, déclaré avec opaque.
Valeur intégrée
Constante ou procédure fournie par le compilateur, par exemple un builtin recensé dans le registre.
