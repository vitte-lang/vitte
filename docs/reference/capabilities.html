Portée des preuves

Cette matrice décrit le code et les tests présents dans le dépôt, pas une promesse de compatibilité complète. Le compilateur 0.1.1 n’est pas prêt à être publié : ses gates de release restent ouverts. Le CLI n’expose pas d’identifiant de build ; une version 0.1.1 détectée ne suffit donc pas à certifier un binaire local. Le fichier JSON versionné est la source utilisée par la commande VS Code Vitte: Show Capabilities ; il contient les preuves par ligne et les références de suivi.

Statuts

  • Implémenté : comportement présent et test automatisé pour le périmètre indiqué.
  • Partiel / expérimental : comportement limité ou dépendant du contexte ; la limitation est précisée.
  • Planifié : non annoncé comme capacité active ; le travail est enregistré ci-dessous.
  • Indisponible : le toolchain 0.1.1 n’exécute pas ce comportement.

Un fournisseur LSP n’est annoncé à VS Code que si la ligne correspondante est annoncée dans le manifeste et possède une preuve automatisée. Les réponses de complétion viennent du serveur de langage : l’extension ne remplace plus un délai ou un échec par des candidats heuristiques ou mis en cache.

Exclusions et suivi

  • CAP-LSP-001 — Remplacer les index textuels et heuristiques par les API de symboles/types du compilateur, puis tester workspace symbols, navigation inter-modules, inlay hints et hiérarchies.
  • CAP-CLI-001 — Implémenter ou retirer les commandes vitte test et vitte fmt du contrat du pilote natif ; garder les actions éditeur signalées comme indisponibles d’ici là.
  • CAP-PLATFORM-001 — Fermer les gates Linux x86_64, macOS arm64 et Windows x86_64, puis établir un toolchain cross avant toute annonce multi-cible.
  • CAP-SUGGEST-001 — Garder les moteurs inline opt-in jusqu’à validation de leurs sorties via le compilateur/LSP et rejet des résultats périmés.
  • CAP-DBG-001 — Corriger les régressions DAP/DWARF macOS 0.1.1 et ajouter la couverture Windows avant d’annoncer le backend natif sur ces plateformes.

Références détaillées : support du langage par construction, CLI et diagnostics, et matrice JSON versionnée 1.0.0.
