Docs Architecture

The Vitte website is a static site served from docs/. HTML pages, stylesheets, scripts, and site data are checked into the repository.

Site sources

  • HTML pages live in docs/ and its subdirectories.
  • Site styles and browser scripts live in docs/css/ and docs/js/.
  • The canonical compiler grammar is grammar/vitte.ebnf.

Updating a page

  1. Edit the relevant HTML page in docs/.
  2. Keep its title, viewport, canonical URL, and other page metadata accurate.
  3. Update the matching search-index entry when page content changes.
  4. Update the sitemap when pages are added, removed, or renamed.
  5. Refresh reports and build metadata after the site data changes.

Checked-in site data

  • docs/search-index*.json contains the search indexes.
  • docs/sitemap.xml and docs/robots.txt describe crawling.
  • docs/build-manifest.json and docs/status.json record build metadata.
  • docs/grammar/rules*.json and docs/grammar/grammar.sha256 contain grammar reference data.

Current workflow limitation

This repository checkout does not contain the site-generation scripts previously listed on this page. Editing an HTML page does not automatically refresh the search index, sitemap, SEO reports, or build manifest. Update those checked-in files explicitly, or add and document a generator before relying on automatic refresh.

Freshness note

The file inventory and asset manifest were refreshed on October 21, 2026. No site generator is checked into this repository, so refresh these snapshots manually after changing pages or assets.
