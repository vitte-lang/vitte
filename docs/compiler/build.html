Build and Compiler Paths

Active compiler path

The standard make target builds a stage bootstrap compiler, uses it to compile the native Vitte pipeline, then links that pipeline into the normal executable. The ordinary compile/run frontend uses Vitte code; the host C compiler still handles object generation, linking, and execution.

  1. src/bootstrap/main.c and src/bootstrap/cli/ — process entry, CLI compatibility, source loading, and module-graph assembly.
  2. src/compiler/driver/pipeline.vitte — native pipeline coordinator.
  3. src/compiler/lexer/lexer.vitte, src/compiler/parser/parser.vitte, and src/compiler/sema/sema.vitte — native lexing, parsing, and semantic analysis for ordinary compile/run.
  4. src/compiler/hir/hir.vitte and src/compiler/ir/ir.vitte — native HIR/IR lowering and validation.
  5. src/compiler/backend/c17/ir_emitter.vitte — default C17 emission for supported IR; ast_emitter.vitte handles constructs without IR lowering.
  6. src/bootstrap/backend/c17/ — host C compilation, object generation, linking, execution, and compatibility emission paths.

compile, run, check, --emit-c, and --emit-ir use the native pipeline for its implemented subset. Supported programs route through HIR/IR to the native IR C17 backend; IR-incomplete constructs retain the AST emitter. Arrays and indexing, picks, contract clauses, export aliases, borrowed call results, and several expression forms use the bootstrap compatibility pipeline. Native failures remain authoritative when the native frontend is selected. The host C driver handles object generation, linking, and execution; inspection commands retain bootstrap stages.

Staged native Vitte path

The Vitte parser and semantic surface remain partial. HIR/IR lowering does not yet cover the full language, and parser/sema diagnostic locations in the CLI remain incomplete. At present, make native-frontend stops on source diagnostics in the arena, scanner, HIR, IR, and semantic modules, so it does not produce a fresh linked native executable. A full self-hosted rebuild is not yet established.

Documentation checks

Run make -C src docs-check to check generated CLI and grammar artifacts and grammar-to-frontend synchronization. This check does not prove every feature-status entry; the coverage matrix is reviewed against source and examples.

See the compiler source map and Make targets for file locations and build commands.
